# Simple GPS Recorder : versions publiques

Ce dépôt ne contient que les APK publiés et le fichier `version.json` lu par l'appli pour proposer une mise à jour. Le code source n'est pas ici.

Chaque release porte l'empreinte SHA-256 de son APK dans `version.json`. L'appli refuse tout APK dont l'empreinte diffère.
